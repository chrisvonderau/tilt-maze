# Tilt Maze

A wooden labyrinth game: tilt the board to roll the steel ball into the brass ring. Fifteen levels, star times, and best times kept on each device.

Play it at https://chrisvonderau.github.io/tilt-maze/

- **iPad:** tap Play and allow motion access, then tilt the iPad. Tap Level to set what counts as flat. Lock screen rotation while playing. If the ball ever rolls the wrong way, set Tilt direction to Reversed in the menu.
- **Mac:** move the pointer toward where the ball should roll, or use the arrow keys or WASD.
